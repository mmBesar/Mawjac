# Linux packaging

The Linux artifacts are generated by [`tool/package_linux.sh`](../../tool/package_linux.sh)
from a Flutter release bundle. There is no distro-specific source tree here;
the script stages a root filesystem, then produces:

| Format | Output |
| --- | --- |
| DEB | `dist/mawjac_<version>_<amd64\|arm64>.deb` |
| RPM | `dist/mawjac-<version>-1.<x86_64\|aarch64>.rpm` |
| AppImage | `dist/Mawjac-<version>-<x86_64\|aarch64>.AppImage` |

Layout inside all packages:

```
/opt/mawjac/                  Flutter bundle (mawjac, lib/, data/)
/usr/bin/mawjac               symlink or launcher
/usr/share/applications/mawjac.desktop
/usr/share/icons/hicolor/512x512/apps/mawjac.png
```

Runtime dependencies:

- GTK 3 (`libgtk-3-0t64`/`libgtk-3-0`, `gtk3` on RPM distributions).
- libmpv (`libmpv2`/`libmpv1`, `mpv-libs` on RPM distributions). The AppImage
  does **not** bundle libmpv.
- The C++ runtime and the usual compression/block-device libraries required by
  Flutter's Linux embedder.

Build requirements and CI details are in [docs/BUILDING.md](../../docs/BUILDING.md).
